# 過去の1株配当の調査(会社公式の有価証券報告書から)

`targets.json` の各社について、記録の一番古い期(`oldest_recorded_fy`)より前の1株配当を調べ、
`results.json` に書いてこのブランチ(research-dividends)にコミット・プッシュする。

## 守ること

- 数字の出どころは **会社公式サイトに載っている有価証券報告書(PDF)だけ**。
  IR BANK・株探・みんかぶ・バフェットコード・キタイシホン・Yahoo!ファイナンスなどの集約サイトの数字は使わない
  (URLを探す手がかりにするのは可。EDINET(disclosure2dl.edinet-fsa.go.jp)の有報PDFは可)。
- 見るのは「第一部 第1 1【主要な経営指標等の推移】」の **(2) 提出会社の経営指標等** の表
  (提出会社の表が無い会社は(1)連結の表)。
- 表の値は **書いてあるとおり(分割前の実額のまま)** 記録する。割り戻しはしない(こちらで照合して割り戻す)。
- 発行済株式総数、中間配当、注記(記念配当・特別配当・分割・決算期変更)も記録する。
- 推測で埋めない。読めない・見つからないときは `status` に理由を書いて飛ばす。

## 取り方

1. `target_yuho_fy` の期の有報(決算年月がその期)を開く。そこに `oldest_recorded_fy` を含む5期分が載っている。
   重なる期(`oldest_values_split_adjusted` は分割調整後の値なので、倍率で照合に使える)。
2. 取れたら、さらに5年前の有報(決算年月が5年前)も開き、最大で `want_years` の範囲まで(2〜3本)。
3. 1社あたりの作業が長引くときは、取れたところまで記録して次の会社へ。

## results.json の形

```json
{
  "9433": {
    "name": "KDDI",
    "status": "ok",             // ok / partial / not_found / unreadable
    "sources": [
      {"url": "https://...pdf", "yuho_fy": "2014-03", "kai": "第30期",
       "table": "提出会社",
       "rows": [
         {"fy": "2010-03", "dps": 11000, "interim": 5500, "shares": 4484818, "note": ""},
         ...
       ],
       "notes": "注記の要約(記念配当、分割、決算期変更など)"}
    ]
  }
}
```

- `fy` は決算の年月(YYYY-MM)。`dps`・`interim` は円(書いてある数値のまま)、`shares` は株(千株表記なら株に直す)。
- 途中で何度かコミット・プッシュしてよい(作業が途切れても残るように)。

## 運用メモ

- 調査セッションは Research 環境で **Sonnet(claude-sonnet-5-5)** を指定して作る。照合・取り込み(分割・併合・決算期変更の判断)は元のセッション(Opus)で行う。
- セッションには「配当調査」タグを付け、取り込みが終わったらアーカイブする。

## 3回目: 誤り探し(targets3.json)

各社の `check_fy`(配当が下がって見える年)と、その前後2年の有報の「主要な経営指標等の推移」の表を見て、
`results3.json` に次を記録する(形は results.json と同じ。rows に fy, dps, interim, shares, note)。

- 1株配当・中間配当(書いてあるとおり)・発行済株式総数
- 分割・併合の **効力発生日と比率**、表の注記にある「分割前/分割後」「期首に分割があったと仮定」などの説明
- 記念配当・特別配当の有無と金額
- 最後に `verdict` を一言: 「本当の減配」「分割の年の混在(中間は分割前・期末は分割後)」「分割前の値が割り戻されていない」など

## 4回目: 決算後の株式分割・併合の一覧(splits-found.json)

国内上場企業のうち、**効力発生日が 2025-06-01〜2026-12-31** の株式分割・株式併合(予定を含む)を集め、
`data/research/splits-found.json` に記録する。

- 出どころ: 日本取引所グループ(JPX)の株式分割等の一覧、または会社公式の適時開示(「株式分割に関するお知らせ」など)。
  まとめサイト(株探・IR BANK・みんかぶ等)は手がかりにしてよいが、記録する値は公式で確かめる。
- 形: `{"3099": {"名前": "三越伊勢丹ホールディングス", "効力発生日": "2026-10-01", "比率": 2, "種類": "分割", "出典": "https://..."}}`
  - 比率は 1株→N株 のN。併合(N株→1株)は 1/N(例: 5株→1株 は 0.2)。
  - 同じ会社で複数あれば、配列にする。
- 漏れなく集めることを優先し、確かめきれないものは `"確認": "未"` を付けて残す。
