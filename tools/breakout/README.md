# 新高値ブレイク手法の検証

kenmo式・DUKE。式の新高値ブレイク投資のルールを検証するスクリプト。配当ダッシュボード本体とは独立している。

| ファイル | 何を確かめるか | 株価データ |
|---|---|---|
| `montecarlo.py` | 資金管理(1銘柄1/5・損切り−8〜−10%)で、勝率と損益比がどれだけあれば勝てるか。連敗とドローダウンの大きさ | 不要 |
| `backtest.py` | 52週高値ブレイク+出来高急増で入り、損切り・建値引き上げ・ボックス割れで出る売買ルールの成績。同じ出口でランダムな日に入った場合との比較 | 要る |
| `synthetic.py` | `backtest.py` の検算用の合成データ(先読みバイアスがないか、優位を検出できるか) | 不要 |

## 実データで回す

日足を1つのCSVにまとめる(列: `Date, Code, Open, High, Low, Close, Volume`)。J-Quants の `daily_quotes` をそのまま書き出したものでよい(調整後の列を優先して使う)。上場廃止銘柄も含めること。

```sh
python3 tools/breakout/backtest.py quotes.csv --compare --index topix.csv --trades-out trades.csv
```

`--index` は指数の日足(`Date, Close`)。終値が200日線より上の日だけ新規に入る(相場環境のゲート)。

## 扱っていないもの

- 業績条件(増収率・増益率・ROE・経常利益の四半期推移)とビッグチェンジ。時点データがないと、後から分かった決算で選ぶ先読みになる
- カップウィズハンドル・保ち合いの長さ/値幅・ブレイク回数などの形
- ピラミッディング(買い増し)。初回で上限まで買う扱い
- 値幅制限(ストップ高/安で約定しない日)。損切りはギャップなら寄付で約定とみなす

## 合成データでの検算(2026-10)

- ランダムウォーク3通り: ブレイク入りの期待値は −0.3%〜+0.5%/回で、ランダム入りと区別がつかない(先読みなし)。それでも5銘柄運用の9年の結果は 0.59倍〜1.45倍、最大DD −30〜−45% とばらつく
- 上昇が続く局面を混ぜたデータ: 期待値 +5.4%/回、ランダム入り(+2.7%)を10回中10回上回る(優位は検出できる)
